# Podium Lead Hunter

AI-powered autonomous lead generation platform for local trade businesses. Find leads, qualify them, build websites, and send personalized outreach — all orchestrated by Claude.

## Architecture

```
podium-hackathon/
├── packages/
│   ├── shared/          TypeScript types & config shared across packages
│   ├── agents/          AI orchestrator, lead pipeline, outreach (Node.js CLI + HTTP server)
│   └── web/             Next.js dashboard for monitoring and configuration
├── sites/               Generated static websites for leads (GitHub Pages)
├── supabase/            Database migrations and config
├── data/                Local runtime data (agent runs, lead cache)
└── sales agent/         Legacy standalone sales agent (migrated to packages/agents)
```

### Pipeline Flow

```
Search → Qualify → Enrich → Store → Generate Website → Outreach
```

Each step is a tool that the Claude-powered **ReAct orchestrator** decides when and how to invoke. The orchestrator reasons about the task, picks the right tools, handles errors, and adapts.

### Tech Stack

| Layer | Technology |
|-------|-----------|
| AI Orchestrator | Claude Sonnet 4.6 (ReAct loop with tool use) |
| Lead Search | Claude Web Search, Google Places API, Yelp, Yellow Pages |
| Database | Supabase (PostgreSQL) |
| Email | Resend |
| SMS | Twilio (pending verification) |
| Payments | Stripe payment links |
| Web Dashboard | Next.js 15, React 19, Tailwind CSS 4 |
| Websites | Static HTML generated per-lead, deployed to GitHub Pages |

## Quick Start

### Prerequisites

- Node.js 20+
- pnpm
- Supabase project (for database)
- Anthropic API key (for Claude)

### Setup

```bash
# Install dependencies
pnpm install

# Copy environment variables
cp .env.example .env
# Fill in your API keys (see Environment Variables below)

# Push database schema to Supabase
supabase db push

# Start the web dashboard
pnpm dev
```

### Run the Pipeline

```bash
# Natural language — Claude figures out the rest
pnpm hunt "Find 5 plumbers in Austin, TX"

# More specific
pnpm hunt "Find HVAC and electrical in Denver, CO. Limit to 3 results. Qualify, store, and generate websites."

# Full pipeline with outreach
pnpm hunt "Find 3 roofers in Raleigh, NC. Qualify, enrich, store, generate websites, and start outreach."

# Check database stats
pnpm stats
```

## Packages

### @podium/agents

The core pipeline. Contains the AI orchestrator and all agents.

**CLI Commands:**
```bash
pnpm hunt [task]       # Run AI orchestrator with a natural language task
pnpm stats             # Show database statistics from Supabase
pnpm serve             # Start HTTP server (for Railway deployment)
```

**8 Agent Tools:**

| Tool | Purpose |
|------|---------|
| `search_leads` | Find businesses via Claude Web Search, Google Places, Yelp, Yellow Pages |
| `qualify_leads` | Score leads 0-100 based on phone, website, address, email, status |
| `enrich_leads` | Visit websites to extract emails, social profiles, services, owner info |
| `store_leads` | Upsert leads to Supabase with deduplication |
| `generate_websites` | Build single-page HTML sites with unique layouts per trade |
| `generate_report` | Summarize leads by trade, city, and outreach status |
| `start_outreach` | Send personalized email/SMS using RAC sales methodology |
| `get_database_stats` | Check current database state |

**Scraper Priority:**
1. Google Places API (if key set — most reliable)
2. Claude Web Search (primary fallback — no scraping, no 403s)
3. Yelp (HTML scraping)
4. Yellow Pages (HTML scraping)

**Outreach Sequence:**
| Step | Day | Channels | Description |
|------|-----|----------|-------------|
| 1 | 0 | Email | Initial outreach with demo site link |
| 2 | 3 | Email | Follow-up with new pain point |
| 3 | 7 | Email | Final follow-up with payment link offer |

Messages are generated by Claude using the **RAC (Resolve-Ace-Close)** sales methodology with objection handling skills.

### @podium/web

Next.js dashboard with 4 tabs:

- **Leads** — Filterable table (city, state, trade, status, score) with stats cards
- **Reports** — Breakdown by city/state, trade, and outreach status
- **Pipeline** — Configure and trigger pipeline runs from the UI
- **Agent Activity** — Real-time monitoring of pipeline runs with event timeline

### @podium/shared

Shared TypeScript types and configuration used by both agents and web packages. Defines the `Lead`, `QualifiedLead`, `EnrichedLead`, and `StoredLead` type hierarchy.

## Database Schema

Supabase with 3 tables:

**leads** — Core lead data
- Identity: `id` (uuid PK), `source_id` (unique, from scraper)
- Business: `company_name`, `trade_category`, `phone`, `email`, `website`, `address`
- Location: `city`, `state` (normalized for reporting)
- Pipeline: `qualification_score`, `status`, `enriched_at`, `owner_name`, `services`, `social_profiles`
- Outreach: `outreach_status`, `sequence_step`, `next_follow_up_at`, `site_url`

**outreach_log** — Every email/SMS sent
- `lead_id`, `sequence_step`, `channel`, `subject`, `body`, `sent_at`

**pipeline_runs** + **pipeline_events** — Agent activity tracking
- Run metadata (task, model, status, steps) + event timeline (tool calls, thinking, errors)

## Deployment

### Local Development

```bash
pnpm dev          # Web dashboard at http://localhost:3000
pnpm hunt "..."   # Run pipeline from CLI
```

### Production (Vercel + Railway)

| Service | Package | Start Command |
|---------|---------|---------------|
| Vercel | `packages/web` | `pnpm build` (auto) |
| Railway | `packages/agents` | `pnpm serve` |

Set `PIPELINE_API_URL` on Vercel pointing to your Railway URL. The web dashboard calls Railway's `/run` endpoint to trigger pipelines.

## Supabase Migrations

```bash
# Link to your project
supabase link --project-ref YOUR_PROJECT_REF

# Push migrations
supabase db push

# Create a new migration
supabase migration new my_migration_name
```

Migrations:
1. `initial_schema` — Leads table with all pipeline columns
2. `add_outreach_support` — Outreach status, sequence tracking, outreach_log table
3. `add_pipeline_runs_and_events` — Agent activity tracking tables
